The four .dict.yaml files are unmodified upstream copies. Commonword reads the
tab-separated headwords and Jyutping into an in-memory lookup, preserving alternate
readings. These files support spelling and pronunciation, not translated meanings.
AI definitions are separate, unverified contributions. The ODbL maps dictionary is
not included. To update, download all four files at a single revision and update
this record; restart the app to clear the in-memory index.
